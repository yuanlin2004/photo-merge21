# App icons

Created with the built-in image-generation tool. Transparent source PNGs are retained here, alongside native `.icns` bundles. Run `./scripts/build-icons.sh` after changing the source artwork; the regular app build copies the `.icns` files into each app before signing.

The icon sets include 16, 32, 128, 256, and 512-point representations at 1× and 2× resolution.

## Photo Merge generation prompt

Create ONE production macOS application icon, square 1024x1024, for 'Photo Merge'. No text or lettering. A beautifully crafted rounded-square blue/teal app tile centered with about 8% transparent margin, genuinely transparent outside tile. Inside tile: two crisp white-rimmed photographic panels joined side by side as one image, a fine central seam. Left panel stylized blue mountain landscape with a small warm sun; right panel corresponding teal mountain landscape. Simple bold recognizable silhouette at small sizes. Premium restrained macOS icon finish, soft dimensional highlights, very subtle shadow, front-facing orthographic, no mockup, no surroundings. Cohesive palette deep royal blue, cyan, teal, warm cream sun. The two joined photo panels are the central visual idea. Generous clean composition, professional native desktop app icon.

## Photo Flip generation prompt

Create ONE production macOS application icon, square 1024x1024, for 'Photo Flip', a companion to a photo-merging app. No text or lettering. A beautifully crafted rounded-square deep indigo/blue app tile centered with about 8% transparent margin, genuinely transparent outside tile. Inside tile: a single crisp white-rimmed photo card at a slight horizontal 3D turning angle, showing a stylized teal mountain landscape and a small warm cream sun. A clean bold curved cyan arrow sweeps horizontally around the card, clearly suggesting flipping it over around a vertical axis. Simple readable silhouette at small sizes. Premium restrained macOS icon finish, soft dimensional highlights, very subtle shadow, front-facing tile orthographic, no mockup, no surroundings. Cohesive palette deep royal blue/indigo, cyan, teal, warm cream sun, white photo rim. The horizontal turning photo is the central visual idea. Generous clean composition, professional native desktop app icon.
